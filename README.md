# ハザードカード NFCデモ

NFCタグから地点ごとの防災情報を読む流れを体験できる、全8枚のHTMLスライドです。

公開サイト: https://naka-c1024.github.io/hazard-card-demo/

## 使い方

公開サイト、または `index.html` をブラウザで開きます。「音を鳴らしてデモを開始」を押すと、約3秒の訓練用通知音が鳴ります。ブラウザの自動再生制限に合わせ、操作後に再生します。公式の緊急地震速報音ではありません。音なしで開始することも、手元の音源を選ぶこともできます。選んだ音源はアップロードしません。

- 左右の矢印キー、Space: スライド移動
- 1〜8: 指定のスライドへ移動
- N: 発表メモの表示
- F: 全画面
- M: 音声の切り替え

2枚目でNFCタグをクリックして読取を体験できます。3枚目で候補カードを生成し、全3行を承認してv4を確定。4枚目で書き込みを実行し、2枚目で再読取するとv4を表示します。

## デモの範囲

NFC読取・書き込み・自治体承認・AI生成は画面上のモックです。自治体、施設、距離、承認、参照数、還元額、シミュレーション値は架空のデータです。実際の避難先や防災情報として利用しないでください。

リアルタイムの地震速報受信、実機NFC、Service Worker、Redpineへの接続、課金・支払いは実装していません。参照した技術資料と研究文献はスライド内の「出典・デモの前提」に記載しています。

## 構成と更新

外部ライブラリやビルド処理を必要としない単一の `index.html` です。スライドの表示と操作は外部通信なしで動作します。参考資料のリンク先を開く場合は通信が必要です。

GitHub Pagesは `main` ブランチのリポジトリルートを公開します。`index.html` を変更して `main` にpushすると更新します。`.nojekyll` でJekyll処理を省略します。
